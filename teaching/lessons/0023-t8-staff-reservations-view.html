🏛️ 1. Informed Context: Host Stand Operations

Host Stand Workflow at Sembilu Tegal

When a guest arrives at the host stand for dinner at 19:00:

  1. Host Waiter Wati checks today's reservation screen on GET /api/staff/reservations.
  2. She sees Pak Budi (Party of 4, 19:00). Next to his name, the system shows visit_count: 5 (VIP Guest!).
  3. Host Wati greets Pak Budi warmly and taps "Check In" ➔ Status changes from confirmed to completed.
  4. If a customer calls on the phone to book for tomorrow, Wati uses POST /api/staff/reservations to record the phone booking directly.

Architectural Invariants We Established (ADR-0006)

  • Today's Date Default: GET /api/staff/reservations defaults to date = CURRENT_DATE, ordered by time ASC. Staff can pass ?date=YYYY-MM-DD to check upcoming dates.
  • Customer SQL Join: Reservations query joins the customers table so staff see guest name, phone, and visit_count.
  • Status Lifecycle: PATCH /api/staff/reservations/:id/status updates status between confirmed, completed (check-in), and cancelled.
  • Phone Booking Upsert: POST /api/staff/reservations automatically checks if the customer's phone number exists, incrementing their visit count if returning, or creating a new customer record.

📚 2. Beginner's Code Glossary

JOIN
A SQL operation combining records from two tables (e.g. reservations and customers) based on a matching foreign key.
CURRENT_DATE
PostgreSQL expression representing today's date, filtering out old or future bookings unless requested.
upsert
Database pattern that updates an existing record if found (incrementing visit_count) or inserts a new record if not found.
check-in
Domain action marking a confirmed reservation as completed when guests arrive at the restaurant.

🧩 3. Informed Knowledge: Endpoints Architecture

1. Fetching Today's Host View (GET /api/staff/reservations)

const targetDate = req.query.date ? String(req.query.date) : db.fn.now()

const reservations = await db("reservations")
  .join("customers", "reservations.customer_id", "customers.id")
  .where({ "reservations.branch_id": branchId })
  .whereRaw("DATE(reservations.date) = DATE(?)", [targetDate])
  .select("reservations.*", "customers.name", "customers.phone", "customers.visit_count")
  .orderBy("reservations.time", "asc")
  • join("customers", ...): Merges customer name, phone, and visit count into each reservation object.
  • orderBy("reservations.time", "asc"): Sorts bookings chronologically from morning to evening for host stand timeline viewing.
