# Learning Resources

## Knowledge

- [Zustand GitHub & Docs](https://github.com/pmndrs/zustand)
  Official docs, API reference, and examples. The primary source for everything Zustand.
- [Zustand Docs: create()](https://github.com/pmndrs/zustand/blob/main/docs/reference/apis/create.md)
  Reference for the core `create` function.
- [Zustand Docs: useStore()](https://github.com/pmndrs/zustand/blob/main/docs/reference/hooks/use-store.md)
  Reference for consuming vanilla stores in React.
- [Zustand Guides & Patterns](https://github.com/pmndrs/zustand/blob/main/docs/learn/guides/)
  Official guides on splitting stores, using Context with Zustand, TypeScript patterns, etc.

## Wisdom (Communities)

- [Reactiflux Discord — #zustand channel](https://discord.gg/reactiflux)
  Active community of Zustand users and maintainers. Good for troubleshooting.

## Knex

- [Knex.js Guide](https://knexjs.org/guide/)
  Official docs — query builder, migrations, schema builder. The primary source.
- [Knex GitHub](https://github.com/knex/knex)
  Source code and issue tracker. Useful for finding examples in tests.

## PostgreSQL

- [PostgreSQL Tutorial](https://www.postgresql.org/docs/current/tutorial.html)
  Official tutorial. Start here.
- [PostgreSQL Docs — DDL Constraints](https://www.postgresql.org/docs/current/ddl-constraints.html)
  Foreign keys, primary keys, unique constraints — everything that keeps your data clean.
