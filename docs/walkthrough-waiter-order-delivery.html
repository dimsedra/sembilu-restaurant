Walkthrough: Alur Pengantaran Pesanan Waiter (Floor Delivery Flow)

Sistem: Sembilu Restaurant Operating System Modul: Staff Floor Operations (/staff/orders) & Backend State Machine Pola: FSM + Derived State + Real-time Pub/Sub

1. Gambaran Umum & Masalah yang Diselesaikan

Pemisahan Tanggung Jawab Nyata: Koki Dapur vs. Waiter Lantai Restoran

Sebelumnya, sistem hanya memiliki tombol "Sajikan ke Meja" di layar tablet dapur koki (KDS). Ini menciptakan celah operasional (operational gap): koki menandai pesanan selesai saji padahal makanan baru matang di meja dapur dan belum diantar ke meja tamu oleh waiter.

Fitur baru ini memisahkan peran tersebut secara tegas: Koki fokus memasak hingga status done (Siap Saji di meja dapur), sedangkan Waiter memiliki antarmuka operasional tersendiri di /staff/orders untuk menerima notifikasi lonceng otomatis dan mengonfirmasi bahwa piring telah benar-benar ditaruh di depan tamu (status served).

Kondisi Sebelum Implementasi

  • Koki di dapur yang menekan tombol status served saat makanan selesai dimasak.
  • Waiter tidak punya layar panduan untuk melihat meja mana saja yang piringnya sudah siap diambil di pass counter dapur.
  • Pelacak tamu (/track/:id) melompat ke status "Tersaji" sebelum makanan sampai di meja fisik.

Hasil Setelah Implementasi

  • Koki di dapur hanya memproses masakan sampai tahap done (Siap Diambil).
  • Layar Waiter (/staff/orders) berbunyi lonceng kuningan otomatis via WebSocket dan menampilkan badge piring siap antar.
  • Waiter menekan tombol 1-tap "Konfirmasi Telah Diantar ke Meja" saat piring diletakkan di hadapan tamu.

2. Universal Engineering Mental Models (Konsep Rekayasa)

1. Finite State Machine (FSM) Satu Arah

Status masakan dimodelkan sebagai mesin status terhingga dengan transisi deterministik satu arah: pending → cooking → done → served. Sistem menolak regresi status ilegal di level database dan API guard.

2. Parent-Child Derived State (Agregasi Status)

Status pesanan induk (order) diturunkan secara otomatis dari status item-item anaknya: jika seluruh item sudah served, maka status order otomatis menjadi served. Jika seluruh item done atau kombinasi done + served, status order menjadi done.

3. Real-Time Pub/Sub Event Synchronization

Ketika status piring berubah di server, pesan disiarkan seketika via native WebSocket. Baik layar dapur (KDS), layar waiter di lantai restoran, maupun smartphone tamu yang sedang melacak makanan menerima mutasi data serentak tanpa perlu polling HTTP.

4. Physical Ergonomics & Multi-Tenant Scoping

Antarmuka waiter didesain khusus untuk penggunaan mobile/tablet saat berjalan: target sentuh minimal 44px, kartu kontras tinggi, audio lonceng kuningan sintetis via Web Audio API, serta partisi data multi-cabang terisolasi per token JWT.

4. Bedah Mekanika Kode (Line-by-Line Breakdown)

Backend: State Machine & Propagasi Status Otomatis (server/routes/staff-orders.ts) 
import { Router, Response } from "express"
import { db } from "../db"
import { requireStaffAuth, AuthenticatedRequest } from "./staff"
import { broadcastOrderUpdate } from "../websocket"

const router = Router()

// [FSM GUARD] Daftar transisi status yang valid untuk setiap baris masakan (item).
// Menjamin masakan berpindah status secara satu arah: pending -> cooking -> done -> served
const VALID_ITEM_TRANSITIONS: Record<string, string> = {
  pending: "cooking", // Item baru mulai dimasak oleh koki dapur
  cooking: "done",    // Item selesai dimasak dan siap di meja pikap dapur
  done: "served",     // Item diambil waiter dan disajikan di meja tamu
}

/**
 * PATCH /api/staff/orders/:id/items/:itemId
 * Endpoint untuk mengubah status item masakan satuan (misal: koki mematangkan 1 piring, atau waiter mengantar 1 piring)
 */
router.patch("/:id/items/:itemId", requireStaffAuth, async (req: AuthenticatedRequest, res: Response) => {
  const staff = req.staff!
  const orderId = Number(req.params.id)
  const itemId = Number(req.params.itemId)
  const { status: newStatus } = req.body

  try {
    // 1. Ambil data pesanan induk untuk verifikasi akses cabang staf
    const order = await db("orders").where({ id: orderId }).first()
    if (!order) {
      res.status(404).json({ error: "Order not found" })
      return
    }

    // 2. Proteksi multi-tenant: Waiter/Chef hanya boleh mengubah order di cabangnya sendiri
    if (!checkBranchAccess(staff, order.branch_id)) {
      res.status(403).json({ error: "Forbidden: Cannot update order belonging to another branch." })
      return
    }

    // 3. Ambil item saat ini dan validasi transisi FSM
    const currentItem = await db("order_items").where({ id: itemId, order_id: orderId }).first()
    if (!currentItem) {
      res.status(404).json({ error: "Order item not found" })
      return
    }

    // Cegah perubahan status yang tidak sesuai urutan mesin status
    if (VALID_ITEM_TRANSITIONS[currentItem.status] !== newStatus) {
      res.status(400).json({
        error: `Invalid transition from ${currentItem.status} to ${newStatus}`,
      })
      return
    }

    // 4. Update status baris masakan di database
    await db("order_items")
      .where({ id: itemId })
      .update({ status: newStatus, updated_at: db.fn.now() })

    // 5. [DERIVED STATE] Hitung ulang status pesanan induk berdasarkan seluruh item anaknya
    const allItems = await db("order_items").where({ order_id: orderId })
    const allDoneOrServed = allItems.length > 0 && allItems.every((i) => i.status === "done" || i.status === "served")
    const allServed = allItems.length > 0 && allItems.every((i) => i.status === "served")
    const anyCookingOrDoneOrServed = allItems.some(
      (i) => i.status === "cooking" || i.status === "done" || i.status === "served"
    )

    // Tentukan status induk baru:
    let newOrderStatus = order.status
    if (allServed) {
      newOrderStatus = "served" // Seluruh makanan sudah tersaji di meja tamu
    } else if (allDoneOrServed) {
      newOrderStatus = "done"   // Seluruh makanan sudah matang (sebagian mungkin sudah disajikan)
    } else if (anyCookingOrDoneOrServed && order.status === "pending") {
      newOrderStatus = "cooking" // Minimal ada 1 makanan yang mulai dimasak
    }

    // Update pesanan induk hanya jika statusnya memang mengalami perubahan
    if (newOrderStatus !== order.status) {
      await db("orders").where({ id: orderId }).update({
        status: newOrderStatus,
        updated_at: db.fn.now(),
      })
    }

    // 6. [REALTIME BROADCAST] Siarkan perubahan ke seluruh client aktif (KDS, Waiter, Customer)
    const updatedOrder = await db("orders").where({ id: orderId }).first()
    const updatedItem = await db("order_items").where({ id: itemId }).first()
    broadcastOrderUpdate({
      type: "order_updated",
      order: updatedOrder,
      item: updatedItem,
    })

    res.json({ item: updatedItem, orderStatus: newOrderStatus, order: updatedOrder })
  } catch (err) {
    console.error("Error updating order item status:", err)
    res.status(500).json({ error: "Internal server error" })
  }
})

Mekanika & Sebab-Akibat Kode:

  • Input: Request HTTP PATCH memuat orderId, itemId, dan status target ("served").
  • Validasi FSM: Memeriksa status saat ini di VALID_ITEM_TRANSITIONS. Jika status awal adalah done, status hanya diizinkan bertransisi ke served.
  • Agregasi Status Induk: Mengevaluasi array seluruh item saudara. Jika seluruh item anak telah bernilai served, status order induk otomatis dipromosikan ke served.
  • Output: Data database termutasi secara atomik dan disiarkan secara instan melalui broadcastOrderUpdate ke WebSocket client.
Komponen UI: Kartu Pesanan Meja Waiter (src/components/staff/WaiterOrderCard.tsx) 
import React from "react"
import { cn } from "../../utils/cn"
import { KDSOrder } from "./KDSAggregateBar"
import { formatElapsedTimer, getElapsedSeconds } from "./KDSTicketCard"
import { CheckCircleIcon, FlameIcon, ChiliIcon } from "./icons"

interface WaiterOrderCardProps {
  order: KDSOrder
  onServeOrder: (orderId: number) => void
  onServeItem?: (orderId: number, itemId: number) => void
}

/**
 * Komponen Kartu Pesanan untuk Layar Waiter
 * Menampilkan status meja, timer durasi, rincian menu masakan, dan tombol aksi pengantaran.
 */
export function WaiterOrderCard({ order, onServeOrder }: WaiterOrderCardProps) {
  // Hitung durasi waktu sejak pesanan dibuat (dalam detik)
  const elapsed = getElapsedSeconds(order.created_at)

  // Status komputasi: Apakah makanan sudah siap diambil di meja dapur?
  const isReadyForPickup =
    order.status === "done" ||
    (order.items?.length > 0 &&
      order.items.every((i) => i.status === "done" || i.status === "served") &&
      order.status !== "served")

  // Status komputasi: Apakah seluruh piring pesanan ini sudah diantar ke meja tamu?
  const isAllServed =
    order.status === "served" ||
    (order.items?.length > 0 && order.items.every((i) => i.status === "served"))

  return (
    <div
      className={cn(
        "flex flex-col rounded-xl border p-4 shadow-lg transition-all",
        // Berikan highlight emas dan border bercahaya jika piring siap diambil di dapur
        isReadyForPickup && !isAllServed
          ? "border-emas bg-ink-2 ring-2 ring-emas/30"
          : isAllServed
          ? "border-line/60 bg-ink-2/50 opacity-75"
          : "border-line bg-ink-2"
      )}
    >
      {/* Header Kartu: Nomor Meja & Indikator Waktu */}
      <div className="flex items-center justify-between border-b border-line pb-3">
        <div className="flex items-center gap-3">
          {/* Badge nomor meja berukuran besar dengan warna emas pusaka */}
          <span className="flex h-10 w-10 items-center justify-center rounded-lg bg-emas font-display text-lg font-bold text-ink">
            {order.table_number}
          </span>
          <div>
            <h3 className="font-display font-semibold text-cream">Meja {order.table_number}</h3>
            <p className="text-xs text-cream-dim">{order.customer_name || "Tamu Walk-in"}</p>
          </div>
        </div>

        {/* Status Badge & Timer Urgensi */}
        <div className="flex items-center gap-2">
          <span className="rounded bg-ink-3 px-2 py-1 font-mono text-xs text-cream-dim">
            ⏱ {formatElapsedTimer(elapsed)}
          </span>
          {isReadyForPickup && !isAllServed ? (
            <span className="inline-flex items-center gap-1 rounded-full bg-emas/15 px-2.5 py-0.5 text-xs font-semibold text-emas">
              <span className="h-1.5 w-1.5 rounded-full bg-emas animate-pulse" />
              Siap Diantar
            </span>
          ) : isAllServed ? (
            <span className="inline-flex items-center gap-1 rounded-full bg-emerald-950 px-2.5 py-0.5 text-xs font-semibold text-emerald-400">
              ✓ Tersaji
            </span>
          ) : (
            <span className="inline-flex items-center gap-1 rounded-full bg-amber-950 px-2.5 py-0.5 text-xs font-semibold text-amber-400">
              <FlameIcon className="h-3 w-3" /> Sedang Dimasak
            </span>
          )}
        </div>
      </div>

      {/* Rincian Menu Sajian & Sambal */}
      <div className="my-3 flex-1 space-y-2">
        {(order.items || []).map((item) => (
          <div
            key={item.id}
            className={cn(
              "flex items-start justify-between rounded-lg p-2.5 text-sm",
              item.status === "done"
                ? "bg-emas/10 border border-emas/30"
                : item.status === "served"
                ? "bg-emerald-950/20 border border-emerald-800/30"
                : "bg-ink-3/60 border border-line/40"
            )}
          >
            <div>
              <div className="flex items-center gap-2">
                <span className="font-semibold text-emas">{item.quantity}x</span>
                <span className="font-medium text-cream">{item.dish_name}</span>
              </div>
              {item.sambal_name && (
                <div className="mt-1 flex items-center gap-1 text-xs text-cream-dim">
                  <ChiliIcon className="h-3 w-3 text-bata" />
                  <span>{item.sambal_name}</span>
                </div>
              )}
              {item.notes && <p className="mt-0.5 text-xs italic text-muted">"{item.notes}"</p>}
            </div>

            {/* Pill status piring satuan */}
            <span
              className={cn(
                "rounded px-2 py-0.5 text-xs font-medium",
                item.status === "done"
                  ? "bg-emas text-ink font-semibold"
                  : item.status === "served"
                  ? "bg-emerald-900 text-emerald-300"
                  : "bg-ink-3 text-muted"
              )}
            >
              {item.status === "done" ? "Siap" : item.status === "served" ? "Tersaji" : "Dimasak"}
            </span>
          </div>
        ))}
      </div>

      {/* Footer Aksi: Tombol 1-Tap Konfirmasi Pengantaran (Target Sentuh >= 44px) */}
      <div className="pt-2">
        {!isAllServed ? (
          <button
            type="button"
            onClick={() => onServeOrder(order.id)}
            className="flex min-h-[44px] w-full items-center justify-center gap-2 rounded-lg bg-emas px-4 py-2.5 font-sans text-sm font-semibold text-ink shadow transition hover:bg-emas-bright active:scale-[0.98]"
          >
            <CheckCircleIcon className="h-4 w-4" />
            Konfirmasi Telah Diantar ke Meja
          </button>
        ) : (
          <div className="flex min-h-[44px] items-center justify-center text-xs font-semibold text-muted">
            Pesanan telah diantar ke Meja {order.table_number}
          </div>
        )}
      </div>
    </div>
  )
}
